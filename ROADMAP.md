# Create: Wire Rider — Roadmap & Update Tracker

План развития мода и подготовка к грядущим обновлениям Create: Electro Energetics (CEE) и Create: Power Grid.

---

## 1. Грядущее обновление CEE (Переменный ток / AC Update)

Разработчик CEE (`George_VI`) готовит переход на расчет переменного тока (AC), трансформаторы и частотную модуляцию:

- **Частотный гул ЛЭП (50/60 Гц)**:
  - При езде по линиям переменного тока генерировать характерный низкочастотный индукционный гул («bzzzz / hum»), громкость которого зависит от силы тока и напряжения.
- **Емкостные и скин-эффекты**:
  - На переменном токе высокое напряжение передается по поверхности проводника (skin effect). На неизолированных проводах переменного тока частота возникновения QTE-разрядов должна быть выше, но время на реакцию чуть мягче, чем на жестких выбросах постоянного тока (DC).
- **Трансформаторные подстанции и фазы**:
  - При проезде через понижающие/повышающие подстанции и трансформаторы визуализировать кратковременную дугу переключения секций.
- **Трехфазные цепи (A, B, C)**:
  - На трехпроводных подвесах учитывать фазный сдвиг при скольжении.

## 2. Мониторинг обновлений CEE и Power Grid

Чтобы своевременно обновлять мод под новые версии CEE и Power Grid:

1. **Скрипт проверки версий (`scripts/check_dependencies.py`)**:
   - Опрашивает API Modrinth и GitHub Releases на наличие новых версий `create-electroenergetics` и `powergrid`.
   - Запускается вручную или по расписанию в GitHub Actions.
2. **Мягкие диапазоны версий (`neoforge.mods.toml`)**:
   - Уже настроены диапазоны `[1.1.0,)` и `[0.6.0,)` с `type="optional"`. Если CEE выпускает минорные патчи, игра не крашится из-за строгой привязки к конкретному билду.
3. **Изолированные адаптеры (`compat.cee` и `compat.powergrid`)**:
   - При любых изменениях внутренней симуляции CEE (например, замена `wireSimulationState.getConnection` на AC solver), обновляется только класс `CEECompat.java`. Ядро мода, физика и другие аддоны остаются нетронутыми.

## 3. Идеи для будущих фич

- **Звук трения ролика/карабина о кабель**: динамический звук скольжения металла по витому сталеалюминиевому тросу с питчем от скорости.
- **Механический держатель (Zipline Handle / Карабин)**: отдельный крафтовый инструмент в Create (медный/латунный ролик на подшипнике) с повышенной скоростью и сниженным трением.
- **Изолирующие перчатки**: экипировка в слот перчаток / брони, снижающая урон от разряда при ошибке QTE.
